# 共同工程规范与环境门

## 1. Source Identity Gate

每个项目必须分别记录：

- project root / implementation worktree / reference tree；
- branch / HEAD / last good commit / git status；
- editable/import path 与 native extension path；
- upstream pin、reference snapshot 与角色；
- allowed/read-only/forbidden source。

禁止修改 study tree、错误 worktree、reference repo 或未知 dirty source。

## 2. Environment Gate

顺序固定：

~~~text
repo identity
→ Python
→ torch/CUDA ABI
→ native extension import
→ Triton/backend actual enablement
→ GPU identity
→ model/tokenizer
→ minimal smoke
~~~

未知项写 TO_FREEZE，不能根据旧环境猜。P2 的 torch/native extension ABI 是 release-blocking gate。

## 3. Runtime Baseline

P1 MVP：

- vLLM v0.26.0 / pinned commit；
- single A100 80GB；TP/PP/DP=1；
- dense full attention、BF16 KV、one KV group；
- eager、prefix caching/spec/async/CUDA Graph off；
- reclaim only after last-prefill forward；
- first post-reclaim q_len=1。

P2 V1：

- same vLLM pin；
- LMCache a7afade compatibility commit；
- local filesystem L2；
- raw baseline before custom Serde；
- no RDMA/Mooncake/NIXL/multi-node/P-D。

## 4. Correctness Levels

~~~text
L0 format/math oracle
→ L1 ownership/state
→ L2 runtime component
→ L3 single-request E2E
→ L4 multi-request/lifetime
→ L5 capacity/serving
~~~

P1 V2/P2 V2 kernel另有 microbenchmark 与 NCU，不得替代 E2E correctness。

## 5. Evidence Package

每个 experiment/run 固定：

- Git SHA、environment、model/tokenizer；
- workload、shape、batch/concurrency、config；
- warmup、repeats、seed/统计方法；
- exact command；
- raw result、processed result、analysis；
- valid/invalid status 与原因；
- source Task/Slice。

大型 Nsys/NCU/trace 留在原目录，Artifact Index 只登记路径。

## 6. Metrics Language

P1：

- deterministic：request-owned blocks、effective occupancy、BlockPool free pages、released-ID reuse。
- conditional：admission、concurrency、preemption、TPOT、throughput、quality。
- forbidden inference：free page ⇒ CUDA HBM returned。

P2：

- deterministic：serialized object bytes、filesystem bytes、L2 bytes、fixed-budget L2 capacity。
- conditional：store/load latency、cache-hit TTFT、throughput、codec performance。
- forbidden inference：generic Serde ⇒ raw first D2H reduced。

## 7. Git and Rollback

一个 Slice 一个最小 diff。禁止无关重构/format。先记录 start HEAD/status，结束执行 diff check、限定测试、status。rollback 优先 feature-off 或本 Slice 原子 commit；不得 reset/stash/覆盖用户改动。
