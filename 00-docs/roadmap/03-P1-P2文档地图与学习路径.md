# P1 / P2 文档地图与学习路径

先理解：

- vLLM Scheduler、KVCacheManager、SingleTypeKVCacheManager、BlockPool；
- GPUModelRunner、Persistent InputBatch、BlockTable、slot mapping；
- KV Connector、LMCache MemoryObj、Serde、L2 adapter；

- Triton paged addressing、NSYS/NCU 分工。

共同学习资料不能直接证明项目功能完成。

## 目录映射

- 00-overview：项目是什么、为什么、边界、当前状态、导航。
- 10-design：Why / Owner / State / Invariant / Failure / Fallback。
- 20-execution：Milestone / Parent Task / candidate slice boundary / Gate。
- 30-evaluation：oracle、benchmark、profiler 与 claim rule。
- 40-agent：Codex session、Task 执行、fallback tree。
- 50-delivery：reference ownership、最终报告、简历/面试。
- 90-reference：仅新 baseline 的 traceability；不放旧 active design。
- process/runtime：跨会话状态派生入口。
- learning：理解；decisions：项目内部稳定取舍；04-experiments：证据。
